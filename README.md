# ChatSphere 💬

A modern full-stack real-time chat application built using the MERN Stack. ChatSphere enables users to connect instantly through secure real-time messaging with a clean, responsive, and user-friendly interface.

---

## 🚀 Features

### 🔐 Authentication & Security
- User Signup and Login
- JWT-based Authentication & Authorization
- Protected Routes
- Secure Password Handling

### 💬 Real-Time Communication
- Instant Messaging with Socket.io
- Real-Time Message Updates
- Online/Offline User Status
- Live User Connections

### 👤 User Profile Management
- Profile Picture Upload
- User Information Management
- Personalized User Experience

### 🎨 Modern UI/UX
- Clean and Responsive Design
- Mobile-Friendly Interface
- Attractive Chat Layout
- Smooth User Experience

### ⚡ Performance
- Fast Real-Time Communication
- Optimized State Management using Zustand
- Efficient Backend Architecture
- Error Handling on Client and Server Side

## ⚙️ Environment Variables

Create a `.env` file inside the backend directory:

```env
MONGODB_URI=your_mongodb_connection_string

PORT=5001

JWT_SECRET=your_jwt_secret

CLOUDINARY_CLOUD_NAME=your_cloud_name

CLOUDINARY_API_KEY=your_cloudinary_api_key

CLOUDINARY_API_SECRET=your_cloudinary_api_secret

NODE_ENV=development
```

## 📦 Installation

### 1. Clone Repository

```bash
git clone https://github.com/your-username/chatsphere.git
```

### 2. Install Dependencies

Frontend

```bash
cd frontend
npm install
```

Backend

```bash
cd backend
npm install
```

### 3. Start Backend Server

```bash
npm run dev
```

### 4. Start Frontend

```bash
npm run dev
```
